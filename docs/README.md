# docs/ — 사람 문서 (비즈니스 진실)

사람이 작성하고 유지하는 **영속적 문서** 보관소. git으로 추적된다.

## 무엇을 넣나
- **사양 (specs):** 기능 요구사항, 화면/플로우 정의
- **결정 기록 (decisions):** 왜 이렇게 했는지 (ADR 형식 권장)
- **비즈니스 룰 (rules):** 계좌·송금·권한 등 도메인 규칙

## 원칙
- 여기 있는 내용이 **비즈니스 진실의 출처**다.
- AI 작업 로그·중간 산출물은 절대 여기 두지 않는다 → `.dev/` 사용.
- 하위 폴더(`specs/`, `decisions/`, `rules/` 등)는 필요에 따라 자유 구성.
